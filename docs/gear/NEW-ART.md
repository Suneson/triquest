# New art for feats and challenges

Every picture this feature needs, as one list to batch through Gemini. The
house style matches the 64 items already in `icons/Pixelart/GEAR/` (see
`docs/gear/art-check.png`). Every prompt ends with the same style line, so
the batch comes out as one family.

**How the files are used:** until a file exists the app draws a stand-in
(a framed pixel board, an `svg()` trophy, a silhouette), so nothing breaks
in the meantime. Square, 1024×1024 out of the model; the existing pipeline cuts
the background and fits it to 128×128 (`tools/gen-items.mjs`'s `cutout` +
`snap` steps), so a flat navy background keys as well as the green one did.
Nothing here is animated.

The style line on every prompt:

> Isometric pixel art in the MOSKE style: clean 1-pixel dark outline, soft cel shading in 3-4 tones per colour lit from the top left, gold (#F2C14E) and MOSKE blue (#0C4CAE) accents, on a flat solid navy background (#0B1222), one object centred filling about 80% of the frame, no text, no letters, no numbers, no watermark, no ground shadow.
